  • LLM never does arithmetic — every number comes from a deterministic (rule-based) tool; the ⓘ button shows that math.
  • Data never leaves the network — model served on-prem; code in client GitLab.
  • Metrics & rules are SQL/config specs the business can sign off.

Data & Files

What we ingest, the grain, and the domain meaning of each field.

File types accepted

  • .xlsx (Excel) — parsed in-browser, no libraries
  • .csv / .tsv — delimiter auto-detected
  • Weekly demand file + optional CQN mapping file

Grain & key

  • Keyed on Forecast_name × Fiscal_Week
  • Forecasting is based on Forecast_name
  • Mapping file (optional) resolves sequence → Forecast_name

Scale

  • ~100 queues scanned weekly
  • Handles 100k+ rows with chunked parsing
  • Top-N affected queues surfaced

Domain knowledge

  • Final_Y1–Y5 = installed units under warranty year 1–5 (demand driver, not prior-year actuals)
  • ASU = Planned/Actual service driver (exact acronym to confirm)
  • Mon–Sun = day-level holiday/weekend flags

Scope

  • Keyed on Forecast_name — forecasting is per forecast_name
  • Priority: 2–3 forecast_names, not the whole file
  • Filter to the target forecast_names, then read RCA

Metrics (only these two)

  • Forecast Accuracy = (Actual_Offered ÷ fcst_offered) × 100
  • Plan Adherence = (1 − Actual_Offered ÷ fcst_offered) × 100 — signed (negative = under-forecast, positive = over-forecast)
  • Flag when |Plan Adherence deviation| > band %

Definitions & Formulas

Field headings, meaning, and the exact formula each rule-based tool computes.

Formulas — the only two computed

MetricExcelPython (rule-based tool)
Forecast Accuracy=(Actual_Offered / fcst_offered) * 100(actual_offered / fcst_offered) * 100
Forecast Adherence=IF(Actual_Offered="","",(1-(Actual_Offered/fcst_offered))*100)"" if actual_offered=="" else (1-(actual_offered/fcst_offered))*100
Forecast = fcst_offered (ML). Keyed on Forecast_name. Both shown as %. Forecast Accuracy is the traditional formula; Forecast Adherence is the formula used in the current Excel system — signed (negative = actual ran above forecast / under-forecast, positive = actual ran below forecast / over-forecast). Flag = accuracy outside ±10% (≡ |forecast-adherence| > 10%). No other formulas are computed — nothing is inferred or invented.
